# Security policy

## Supported versions

Only the latest release, the one running at [yoko.arualvivan.com](https://yoko.arualvivan.com), gets security fixes.

## Reporting a vulnerability

Please don't open a public issue, discussion or PR for a vulnerability.

Report it privately through GitHub: go to the repository's **Security** tab and click **Report a vulnerability**. Only the maintainer can see the report.

Include, if you can:

- what is affected (a page, an endpoint, a file);
- the steps to reproduce it;
- what an attacker could do with it.

## What to expect

- An answer within 5 business days.
- Updates while the fix is in progress.
- Credit in the advisory once the fix is released, if you want it.

## Scope

In scope: the code in this repository and the app at [yoko.arualvivan.com](https://yoko.arualvivan.com).

Out of scope: third-party services Yoko uses (report those to their owners), denial of service, and social engineering.
