Design reference

The screens and the design tokens live in the HTML prototype at docs/prototypes/platform/. It is the living reference for the interface (decision 005).

The prototype winsThe code never gets ahead of the prototype. If a screen or token is different in the code, the prototype is right and the code is fixed.

Changing the design

  1. Change the prototype.
  2. Validate it.
  3. Implement it in client/.

Design tokens

The tokens are defined in tokens.css and copied to client/src/assets/sass/tokens/ with the same names:

/* prototype */            /* SASS */
--bg-default            →  $bg-default
--border-r-default      →  $border-r-default
--text-sm               →  $text-sm
  • Colors: base, categories, semantic, themes, shell and task status.
  • Typography: Quicksand, from text-xs to text-xl.
  • Effects: radius, border width, shadow and opacity.
  • Breakpoints: mobile first, at 481px, 769px and 1280px.
