# Used technologies

## yoko

Not a dependency

- **Local storage:** for store data that is not fully persistent

Dependencies

- **React:** for building reactive and dynamic interfaces. Use context with reducer to create global state management (https://react.dev/)
- **React dom:** entry point to the DOM and server renderers for React (https://react.dev/reference/react)
- **React router:** to enable navigation in SPA (https://reactrouter.com/)

Dev dependencies

- **Vite:** for bundling, HMR, etc (https://vite.dev/)
- **TypeScript:** to use types with javascript (https://www.typescriptlang.org/docs/)
- **Eslint:** to help with code quality and patterns (https://eslint.org/docs)
  - SonarJS, access [rules](https://github.com/SonarSource/SonarJS/blob/master/packages/jsts/src/rules/README.md)
- **Prettier:** to help with code formatting (https://prettier.io/docs/)
- **Husky:** automating eslint and prettier before commiting (https://typicode.github.io/husky/)
- **Vitest:** writing unit and integration tests (https://vitest.dev/)
- **Testing Library:** to test UI - integration tests (https://testing-library.com/)
- **SASS:** for styling (https://sass-lang.com/guide/)
- **Semantic release:** for automating the version control of the releases (https://semantic-release.org/)

## yoko-docs

The tool behind the website that keeps all the client and development documentation needed is [docusaurus](https://docusaurus.io/)

## Tools for general purpose

- **Mermaid:** to create diagrams in md/mdx files (https://mermaid.js.org/)
- **Git:** for versioning control (https://git-scm.com/)
